CEUCRUD

Sistema de gerenciamento universitario desenvolvido em Python com CustomTkinter, integrado a API publica do IBGE e conectado a banco de dados em nuvem via TiDB Cloud.

Ver repositorio Ver detalhes do projeto

Sobre o Projeto

O CEUCRUD permite cadastrar, listar, atualizar e excluir dados de cursos, alunos, funcionarios, materias e matriculas. Nesta entrega final, o foco foi consolidar o trabalho colaborativo em equipe com Pull Requests, testes, pipeline de CI e persistencia em banco real na nuvem.

Tecnologias Utilizadas

  • Python 3
  • CustomTkinter
  • MySQL
  • TiDB Cloud
  • API publica do IBGE
  • unittest e pytest
  • GitHub Actions
  • GitHub Pages

Funcionalidades

  • CRUD completo de cursos
  • CRUD completo de alunos
  • CRUD completo de funcionarios
  • CRUD completo de materias
  • CRUD completo de matriculas
  • Consulta de municipios por UF com a API do IBGE

Banco em Nuvem

A aplicacao foi configurada para usar variaveis de ambiente e se conectar a um banco remoto no TiDB Cloud, evitando credenciais fixas no codigo.

Exemplo de configuracao local: .env com DB_HOST, DB_PORT, DB_USER, DB_PASSWORD e DB_NAME.
